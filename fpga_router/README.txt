Router on the Urbana FPGA (XC7S50-CSGA324)

router_core.v       dot product, bias, compare. 4 clocks
router_frontend.v   123-byte packet -> 16 features (13 popcounts + 3 numbers)
uart_rx.v uart_tx.v 8N1 serial, 115200 baud at 100 MHz
router_top.v        top level: clk_100mhz, uart_rxd, uart_txd, led[15:0]
tb_router.v         testbench, prints PASS or FAIL
urbana_router.xdc   pins. Check them against RealDigital's master XDC
router_fpga.py      host side: shots, standin, export, send
router_params.vh vectors.mem tb_vectors.vh   generated by "export" from model.npz and shots.npz
shots.npz           300 Stim shots from the kit at p = 0.004, X memory
model.npz           STAND-IN weights. Not a trained router. Replace with router_v1.npz

Simulate (must print PASS):
  verilator --binary --timing -Wno-fatal --top-module tb_router -I. tb_router.v router_top.v router_core.v router_frontend.v uart_rx.v uart_tx.v
  ./obj_dir/Vtb_router
New weights:
  python router_fpga.py export router_v1.npz shots.npz
On the board:
  python router_fpga.py send COM5 router_v1.npz shots.npz

Checked in a sandbox: simulation passes on the 300 shots, Yosys synthesis gives 1,105 LUTs, 611 flip-flops, 16 DSP slices.
Not checked: timing at 100 MHz, and the board itself.
